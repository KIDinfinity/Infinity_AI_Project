基于乐酷 Mini + DeepSeek 自主接单编码 Agent 方案文档
文档用途：项目总体规划、模块拆分、落地路线、技术选型；可直接复制保存为 agent_plan.md
定位：半自主优先，逐步放开权限，优先做你的智能外包助理，不一开始就做 7×24 无人挂机机器人，规避封号、失控风险
硬件：乐酷 Mini 主机（Windows）
大模型：DeepSeek 系列（API 优先，后期可 Ollama 本地量化备选）
一、项目概述
核心目标
Agent 具备一套闭环能力：
浏览器自动化：登录接单平台、浏览订单、和客户沟通、上传交付物
桌面电脑控制：打开 IDE、终端、读写文件、执行代码、查看报错
订单智能评估：基于已有技术栈判断能不能接
自主编码调试：拿到需求后迭代写代码、自测、修复 bug
持续沉淀记忆：成功 / 失败案例存入向量库，不断扩充自身能力
核心范式
感知屏幕 → LLM 决策 → 执行动作 → 获取反馈 → 写入记忆库 → 循环
记忆不靠上下文窗口，靠向量数据库实现 “积累技术栈”
模型路由规划
DeepSeek-Coder：需求解析、订单评估、代码生成、bug 修复、话术生成
DeepSeek-VL：屏幕截图理解、识别弹窗、报错界面、验证码、页面结构
辅助 OCR：PaddleOCR，纯文字页面提取文本，节省 VL token 消耗
二、底层基础设施 & 工具栈
1. 视觉感知层（Agent 如何 “看懂电脑”）
表格
组件	选型	作用
屏幕截图	mss	高性能截图，适合 7×24 挂机，比 PIL 更快
图像理解	DeepSeek-VL	截图输入，输出结构化动作 JSON
文字提取	PaddleOCR	页面大段文字提取，减少 VL 调用
动作输出规范（LLM 强制输出 JSON，方便程序解析）
json
{"action":"click","target":"vs_code_run_button","x":450,"y":320}
action 可选值：click / type_input / hotkey / run_terminal / screenshot / wait
2. 动作执行层（两大执行分支，分开管理）
① 浏览器自动化（接单平台网页）
✅ 首选：Playwright + playwright-stealth + playwright-fingerprint
能力：持久化登录状态（storage_state）、指纹伪装、反检测、异步、多上下文隔离
用途：登录、翻订单列表、聊天、上传文件、提交交付
备选：Selenium（不推荐，极易被识别自动化）
② 桌面 GUI 自动化（Playwright 无法完成：VSCode、终端、本地文件）
✅ 首选组合：pywinauto + PyAutoGUI
pywinauto：Windows 原生控件识别，稳定，优先使用
PyAutoGUI：像素级键鼠模拟，控件识别失败时兜底；缺点：分辨率 / 缩放变化容易失效
约束：Windows 系统缩放固定 100%，减少像素定位 bug
③ 编码子 Agent（捷径，不用从零写调试逻辑）
直接复用成熟开源编码 Agent，替换 LLM 后端为 DeepSeek：
Devika
Aider
能力：自动新建项目、读写文件、调用终端、跑测试、迭代修复代码
3. Agent 流程编排层
✅ 选型：LangGraph
作用：状态机管理，控制任务流转：空闲 → 浏览订单 → 评估订单 → 接单 → 编码开发 → 交付 → 复盘；支持分支判断、超时、重试、告警，防止死循环。
4. 长期记忆库（积累技术栈核心）
✅ 选型：Chroma（轻量向量库，乐酷 Mini 轻松跑）
存储内容：历史订单需求、代码、报错日志、解决方案、踩坑总结；新订单进来先检索相似历史案例，辅助评估和开发。
三、业务模块详细设计
模块 1：前置模块｜账号托管 + 环境自检
目标：维持登录、环境就绪、拦截异常弹窗
平台隔离：每个接单平台独立 Playwright 上下文、独立指纹，禁止多账号共用浏览器实例
登录持久化：首次手动登录，保存 storage_state；每次启动加载会话，截图交给 DeepSeek-VL 校验是否登录失效
验证码 / 滑块策略：MVP 阶段人工介入，检测到验证码直接推送告警，不自动打码（降低封号风险）
环境自检：启动自动校验 VSCode、Git、Python/Node 等运行环境；缺失则自动打开终端安装依赖
读写沙箱约束：Agent 仅允许在指定项目目录读写文件，禁止随意修改系统目录
模块 2：订单搜索 + 能力评估模块（判断力模块）
Playwright 定时轮询订单列表，翻页抓取标题、需求描述、预算、工期、附件
DeepSeek-Coder 结构化解析需求：识别技术栈、预估工作量、风险点
向量库检索：查询历史同类订单，给 LLM 参考自身过往能力
打分评估（0~10 分）
≥7 分：可尝试接单（MVP：推送消息给你，人工确认后才继续）
4~6 分：存入【待学习队列】，空闲时段自主写 Demo 学习，更新知识库
≤3 分：直接跳过
沟通子流程：评估通过后 DeepSeek 生成报价 / 答疑话术，Playwright 输入聊天框；定时轮询客户消息
风控规则：页面刷新间隔随机 60~180s，模拟真人浏览，禁止高频请求
模块 3：干活模块｜接单后自主编码、调试、自测（核心闭环）
收到确认接单指令 → 自动创建独立项目目录、初始化 Git
需求拆解，分模块开发，禁止一次性生成超大代码
调用终端执行代码、捕获控制台输出；或者截图 VSCode 报错界面交给 DeepSeek-VL 分析
LLM 迭代修改代码，循环调试；设置最大重试次数（推荐 5 次），防止无限死磕 bug
自主编写单元测试，自测验证功能匹配需求
多次重试失败：判定任务卡住，推送告警，停止自动尝试，等待人工介入
模块 4：交付 + 复盘记忆模块（能力沉淀）
打包产物：压缩代码、整理文档；Playwright 上传至平台交付入口，自动生成交付说明
监听客户反馈：客户提出修改需求，自动进入二次迭代流程
自动复盘（最重要）：任务结束（成功 / 失败），自动整理需求、代码、日志、解决方案，向量化存入 Chroma
简易记账：本地日志记录订单预算、耗时，用于后续评估单价是否划算
模块 5：调度监控 + 告警 + 紧急开关
LangGraph 维护全局状态，每个状态设置超时，超时自动退出并告警
全链路日志：所有动作、截图、LLM 对话、报错，本地落盘保存
消息通知：Server 酱 / 钉钉机器人推送：新订单、验证码、任务卡住、高价订单
硬规则：设置预算阈值，高于阈值的订单强制人工审核，无论评估分数多少，防止接高风险订单
模块 6：风控合规模块（红线）
重要提醒：绝大多数外包接单平台协议禁止脚本 / 爬虫自动化接单，全自动无人挂机存在封号风险
不使用固定 UA、固定鼠标轨迹，stealth 插件隐藏自动化标记
单阶段只跑 1 个账号，不批量多账号爬取
优先定位：你的智能助理，而不是无人挂机机器人
四、分阶段落地路线（按顺序开发，不要跳阶段）
阶段 1：MVP 半自动化（预估 1~2 周可跑通，优先做）
功能清单：
Playwright 登录接单平台，持久化 cookie，定时抓取订单
DeepSeek-Coder 解析需求 + Chroma 评估，筛选合适订单，推送消息给你
你确认接单后，拉起 Aider/Devika 编码子 Agent，调用 DeepSeek-Coder 自主编码调试
开发完成打包，人工确认后 Agent 上传交付
技术栈：Python + Playwright + LangGraph + DeepSeek API + Chroma + mss + pywinauto
阶段 2：迭代 1 — 放开简单沟通
Agent 自动回复客户常规问题（工期、技术方案、简单咨询）；需求变更、高价订单依旧人工审核；持续沉淀案例进向量库。
阶段 3：迭代 2 — 有限自主接单（谨慎开启）
放开自动报价接单，配置预算阈值、风险标签拦截；触发风险条件自动切回人工复核。

六、避坑清单
必须设置 bug 重试上限，禁止 Agent 无限循环重试同一个问题
DeepSeek-VL 按截图计费，不要无意义高频截图；纯文字页面优先 OCR 提取文本
Windows 缩放固定 100%，否则 PyAutoGUI 像素定位极易错乱
不同接单平台使用独立 Playwright 上下文，不要混用 session
乐酷 Mini 跑 API 方案体验最佳；本地 Ollama 量化模型可以玩，但速度不适合接单干活
所有自动化动作增加随机延时，模拟真人，拒绝固定节奏
