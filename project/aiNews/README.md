# project/aiNews —— 每日 AI 技术资讯收集 Agent

## 0. 这是什么

一个**提示词驱动**的小工具，提供两个入口提示词（产出目录完全一致，区别只在最后是否生成文章）：

- [COLLECT_PROMPT_QUICK.md](COLLECT_PROMPT_QUICK.md) —— 精简版：收集 + 筛 Top 3 + 一份 30 秒能读完的简要概括，**不生成文章**。没空细看时用这个。
- [COLLECT_PROMPT_FULL.md](COLLECT_PROMPT_FULL.md) —— 完整版：在精简版基础上，再多生成一篇可直接发布到掘金的文章草稿。

## 1. 它在整个仓库里的位置（重要，不要越界）

- 本仓库根目录是「半年数字资产项目」，当前 DA-01 = `WorkPilot`（见仓库根 `GLOBAL_CONTEXT.md` / `PROJECT_CONFIG.md`）。
- `project/aiNews` **不是 DA-01**，是 `project/` 目录下独立的一个轻量 side project（与 `project/fund` 同级、互不影响）。
- 执行本项目任务时：
  - **只**读写 `project/aiNews/` 目录内的文件；
  - **不要**修改仓库根 `GLOBAL_CONTEXT.md`、`PROJECT_CONFIG.md`、`plan/` 等 DA-01 相关文件；
  - **不要**顺带碰 `project/` 下其他同级项目目录（如 `project/fund`）。

## 2. 怎么用

每次想收集一次资讯时，根据当下有没有空细看，二选一发给 Agent 执行（或说"按 `project/aiNews/COLLECT_PROMPT_QUICK.md`（或 `_FULL.md`）跑一次"）：

1. 读 [sources.md](sources.md)，拿到当前可用的信息源清单；
2. 逐个尝试收集最近的 AI 技术动态，从中挑出最值得关注的 3 条；
3. 如果某个网站打不开 / 某个工具调不通，**自动修复 `sources.md`**（标记失效、找替代源、记一笔自愈日志），不会卡住整个流程；
4. 在 `project/aiNews/{当年}年/{当月}月/{当日}日/` 下生成当天的产出文件（精简版 3 个文件，完整版 4 个文件，见下）。

## 3. 目录结构

| 路径                      | 作用                                                           |
| ------------------------- | -------------------------------------------------------------- |
| `README.md`               | 本文件，项目说明                                               |
| `COLLECT_PROMPT_QUICK.md` | 精简版提示词入口（不生成文章）                                 |
| `COLLECT_PROMPT_FULL.md`  | 完整版提示词入口（多生成一篇掘金文章草稿）                     |
| `sources.md`              | 信息源清单 + 可用状态 + 自愈变更日志（唯一事实来源，不要另建） |
| `{YYYY}年/{MM}月/{DD}日/` | 每次执行生成的当日产出目录，见下                               |

每个「当日产出目录」里的文件（两个提示词产出目录一致，`03_juejin_draft.md` 只有跑完整版才会生成）：

| 文件                 | 作用                                           | 精简版 | 完整版 |
| -------------------- | ---------------------------------------------- | ------ | ------ |
| `00_summary.md`      | 30 秒能读完的简要概括，没空细看时看这个        | ✅     | ✅     |
| `01_collected.md`    | 当次收集到的原始条目（来源、标题、链接、简述） | ✅     | ✅     |
| `02_top3.md`         | 从原始条目里筛出的 Top 3，附选择理由           | ✅     | ✅     |
| `03_juejin_draft.md` | 根据 Top 3 生成的掘金文章草稿，可直接复制发布  | ✗      | ✅     |

## 4. 进度 / 历史记录

不单独建进度文档。每天的产出目录本身就是历史记录；信息源的可用性变化记在 [sources.md](sources.md) 的"自愈变更日志"一节。
