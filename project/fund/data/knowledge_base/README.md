# knowledge_base/ 目录说明

知识沉淀层，系统最核心的资产，三个子目录：

- [fund_profiles/](fund_profiles/) — 每只基金的经验画像，系统自动增量写入
- [lessons_learned/](lessons_learned/) — 从复盘提炼的结构化教训，系统自动追加写入
- [market_patterns/](market_patterns/) — 近几十年市场规律参考库，**只允许人工审阅后入库**，日常自动流程不得写入

详细设计见 [../../design/10_knowledge_base.md](../../design/10_knowledge_base.md)。
