# Week 19 · 扩充 Agent 知识库

## 1. 本周核心目标

扩充 Agent 知识库，持续降低沟通成本，让更多咨询被自动承接。

## 2. 为什么这一周存在

知识库越全，Agent 能自动承接的比例越高，人工沟通越少，睡后收入属性越强。

## 3. 本周在整个半年路线中的位置

```
第 18 周产出：稳定产品 + 新反馈
  ↓
本周：把反馈沉淀进知识库，扩充 Agent 能力
  ↓ 新产出
更全的知识库
  ↓ 下一周输入
第 20 周验证收入是否稳定
```

## 4. 本周必须留下的资产

- 扩充后的知识库
- Agent 自动承接率提升记录

## 5. 本周验收标准（PASS/FAIL）

- [ ] 知识库有实质扩充
- [ ] Agent 自动承接率提升（或回答更准）

## 6. 本周禁止事项

- 不塞入低质量、无关内容
- 不因调知识库忽视产品本身

## 7. 如果只有 7 小时

必做：把高频新问题补入知识库并验证。

## 8. 完成本周后

下一周统计收入，验证月被动收入是否稳定 1000+。
