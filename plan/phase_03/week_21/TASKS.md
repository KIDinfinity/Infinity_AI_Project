# Week 21 · TASKS

## Task 1：本地小模型实验

### 做什么
选一个本地小模型，跑通基础任务（如问答/分类/生成）。

### 为什么做
探索降低长期 LLM API 成本、沉淀自有 AI 能力。

### 对 DA-01 的贡献
为 DA-01 提供更低成本的 AI 方案备选。

### 前置依赖
第 15 周 AI 调优经验 + 私有云环境。

### 具体执行步骤
1. 选型并部署本地小模型。
2. 跑基础任务。
3. 对比效果与成本。

### 验收标准
本地模型能跑通基础任务。

### 完成后的产出
实验记录。

### 如果没有必要
若当前云 API 已满足且成本可控，可降级为 Optional 调研。
