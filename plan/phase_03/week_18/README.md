# Week 18 · 产品小 bug 迭代

## 1. 本周核心目标

根据用户反馈迭代产品小 bug，保持产品质量稳定。

## 2. 为什么这一周存在

放大期持续有用户，小 bug 会累积影响口碑，需要定期收敛。

## 3. 本周在整个半年路线中的位置

```
第 17 周产出：流量增长 + 用户反馈
  ↓
本周：修复小 bug，稳定产品
  ↓ 新产出
更稳定的产品版本
  ↓ 下一周输入
第 19 周扩充 Agent 知识库
```

## 4. 本周必须留下的资产

- 修复的小 bug 记录
- 更新后的产品版本

## 5. 本周验收标准（PASS/FAIL）

- [ ] 用户反馈的 bug 被修复
- [ ] 无回归问题

## 6. 本周禁止事项

- 不借机新增功能
- 不忽视用户反馈

## 7. 如果只有 7 小时

必做：修复高优先级 bug。可删：低优先级细节。

## 8. 完成本周后

下一周扩充 Agent 知识库，持续降低沟通成本。
