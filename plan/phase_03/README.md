# Phase 03 · 迭代放大期（第 17–26 周）

## 1. 阶段目标

稳定睡后收入、沉淀可复用 AI 资产、完成半年复盘并规划下一阶段商业化方向，把「做一个产品」升级为「可复制生产数字资产的方法」。

## 2. 为什么这个阶段存在

半年目标不只是「完成一个项目」，而是「形成可重复的数字资产生产能力」。本阶段把 DA-01 的经验固化成 DA-02、DA-03 可以复用的方法与资产。

## 3. 本阶段必须产生什么

- P3 完整AI生产级应用（B 线）：DA-01 稳定运行 + Security + Guardrail + Evaluation v2 + Badcase 回归测试。
- 个人AI工程作品集 / Portfolio 网站上线（D 线）：GitHub + 个人网站 + Demo，展示 P1+P2+P3。
- AI 简历最终版 + 面试准备（D 线）：System Design 能力 + 3 分钟讲清每个项目。
- 稳定月被动收入（目标 1000–2000 元）与持续订单流水（A 线）。
- 完全成熟、可迁移可备份可复用的私有云底座（C 线）。
- 半年收入/流量/成本数据复盘。
- Agent 商业化可行性评估。
- 下半年升级方案。

> 主线优先级：D ≈ B > A > C

## 4. 本阶段不应该做什么

- 不盲目扩大产品线、不启动多个新项目。
- 不为「完整」过度建设基础设施。
- 半年内不搬迁、不裸辞、不超预算。

## 5. 本阶段核心能力

**D 线（Job Market）**：Portfolio 网站、AI 简历最终版、System Design 面试能力、3 分钟项目讲解。

**B 线（AI Engineering）**：Production Hardening、Security/Guardrail、Evaluation v2、Badcase 回归测试。

**A 线（产品）**：收入稳定、用户反馈迭代、下半年规划。

**C 线（基建）**：可迁移私有云、监控告警、灾难恢复。

## 6. 本阶段与 DA-01 的关系

DA-01 从「一个能变现的产品」变成「可长期迭代的资产」，并沉淀出复制到下一个数字资产的方法。同时 P3 完成求职作品集的终极交付。

## 7. 进入条件

阶段二完成：已有上架产品、首单收入、Agent 与流量体系。

## 8. 完成条件

月被动收入稳定、AI 资产与复盘文档齐全、下一阶段方向明确。

## 9. 阶段验收标准

- 月被动收入稳定 1000+。
- 私有云可迁移可备份可复用。
- 形成个人 AI 工程作品集与全套文档。
- 完成半年复盘，确定 DA-02 可行性。

## 10. 下一阶段依赖什么

本阶段是半年终点。产出直接决定 DA-02 是否启动、以什么形态启动。

## 完成本阶段后，DA-01 比阶段开始前多了什么？

从一个「已上架产品」变成「稳定产生收入、可迁移可迭代、且能复制出下一个数字资产的可持续资产 + 一套已验证的生产方法」。
