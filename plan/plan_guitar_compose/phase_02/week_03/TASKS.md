# Week 03 · TASKS

## Task 1：《逆流》动机 + 和声 + A 段（Day11 · 11-09）

### 做什么
- 定「增二度动机」：A 和声小调（A B C D E F G#）里用 F→G# 增二度制造紧张。
- 和声：Am–G#dim–Am 或 Am–Dm–E（含减七 G#dim7）。
- 写 A 段 16 小节，速度 120 BPM。

### 为什么做
和声小调的增二度（b6→7）是「异域紧张」，配减七和弦制造「挣扎逆流」。

### 验收标准
- [ ] 增二度动机谱 + 和声表 + A 段 16 小节

## Task 4：《黎明之前》动机 + 和声 + A 段（Day14 · 11-12）

### 做什么
- 定「反转动机」：A 小调半音下行低音，为结尾皮卡第三度（升 C 转 A 大调）埋下伏笔。
- 写 A 段 16 小节，100 BPM。

### 为什么做
这是专辑的「黎明」：前半压抑、结尾转大调，宿命反转。

### 验收标准
- [ ] 反转动机谱 + 和声表 + A 段 16 小节
