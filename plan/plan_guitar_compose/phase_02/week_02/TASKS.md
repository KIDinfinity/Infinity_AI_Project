# Week 02 · TASKS

## Task 1：《轮回》动机 + 和声 + A 段（Day06 · 11-02）

### 做什么
- 定「循环动机」：D 多利安（D E F G A B C）里选一个 2–4 拍音型，配固定低音 ostinato（如低音 D 反复）。
- 和声：D 多利安主和弦 Dm，配 Bb / C / Am 制造循环感（i–VI–VII–i 或 i–bVII–IV）。
- 写 A 段 16 小节。

### 为什么做
多利安的「小调含还原 6」自带苍凉辽阔，ostinato 制造「命运齿轮」的循环感，是全曲情绪核心。

### 验收标准
- [ ] 循环动机谱（2–4 拍）+ 固定低音 ostinato 谱
- [ ] 和声进行表 + A 段 16 小节

## Task 4：《长夜》动机 + 和声 + A 段（Day09 · 11-05）

### 做什么
- 定「b2 半音动机」：E 弗里吉亚（E F G A B C D，b2 = F）用 E–F 半音制造压迫。
- 和声：E 弗里吉亚主和弦 Em，配 F（bII）、Dm、C，持续低音 pedal E。
- 写 A 段 16 小节。

### 为什么做
弗里吉亚的 b2 半音是「宿命压迫」最直接的音，慢速 80 BPM 营造「无望的夜」。

### 验收标准
- [ ] b2 动机谱 + 持续低音 pedal 谱
- [ ] 和声表 + A 段 16 小节
