# Phase 02 · 批量创作第 2~5 首（Week 02–03 · 11-02 → 11-13）

## 阶段目标

用 Phase 01 验证过的「宿命感创作语法」，以每首 2–3 天、每天 60 分钟的速度，完成《轮回》《长夜》《逆流》《黎明之前》四首，使 5 首全部成型。

## 策略

- 每首固定节奏：第 1 天「动机 + 和声 + A 段」，第 2 天「B/C 段 + 完整拼装」，第 3 天「记谱 + 弹奏打磨」（3 天版）或压缩为 2 天（第 2 天合并拼装 + 记谱）。
- 四首在调式、速度、情绪上拉开差异（见 TARGET.md 五首定位表），避免「写得像同一首」。
- 每首完成即记谱，不留债；周末弹性补记谱 / 补录。
