# plan_guitar_compose — 「宿命五章」原创吉他曲创作计划

- **目标**：创作 5 首原创吉他曲，宿命感强，每首约 3 分钟
- **乐器**：吉他（独奏/指弹为主，可叠低音声部）
- **起点水平**：有吉他基础（能弹和弦 / 分解 / 旋律，会看六线谱），具备基础乐理（音阶、和弦级数、调式）
- **每日投入**：60 分钟
- **每周创作**：5 天（周一至周五），周末弹性（补记谱 / 录音）
- **总周期**：4 周（1 个月）
- **起始日期**：2026-10-26（周一）

## 创作方法论（详见 TARGET.md）

宿命感 = 调式（小调/弗里吉亚/和声小调）× 和声（安达卢西亚终止 / 半音下行低音 / 减七 / 皮卡第三度）× 节奏（ostinato / 附点三连音）× 命运动机（下行小二度）。

## 交付物

- 5 首完整乐谱（Guitar Pro `.gp` 或 MuseScore `.pdf`）
- 5 段完整演奏录音（手机/声卡）或 MuseScore 音频 demo
- 每首的 `README`（曲名、调式、和声、结构、动机说明），随 `dayNN/` 内记谱产出
