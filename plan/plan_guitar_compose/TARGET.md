## 核心原则

1. **动机先于音符**：每首先定一个 2–4 拍的「命运动机」，全曲从这里生长，避免拼凑。
2. **和声先行**：先写和声进行（8 小节为单位）再填旋律，和声是「宿命感」的底色。
3. **慢速成形，稳定优先**：新段落先用慢速弹顺，再上目标速度。
4. **记谱与创作同步**：当天写好的小节当天录进 Guitar Pro / MuseScore，不留「靠记忆」的债。
5. **锚点一致**：每天都能回答「今天写的这段，最终属于 5 首曲子的哪一首、哪个情绪节点」。

## 「宿命感」创作语法 v1（全计划共用）

**调式 / 音阶**（苍凉 / 紧张 / 宿命）：
- 自然小调（Aeolian）：悲怆底色
- 和声小调：增二度（b6→7），异域紧张
- 多利安（Dorian）：含还原 6，苍凉辽阔
- 弗里吉亚（Phrygian）：b2 半音，压迫感

**和声进行**：
- 安达卢西亚终止：i–VII–VI–V（如 Am–G–F–E）
- 半音下行低音：Am–Am/G#–Am/G–Am/F#（低音 A→G#→G→F#）
- 减七和弦（dim7）：最强张力过渡
- 那不勒斯 bII：悲剧色彩（小调中插 bII 大三和弦）
- 皮卡第三度（Picardy third）：小调结尾升三大调，宿命反转
- 持续低音（pedal）：固定低音上的和弦流动

**节奏**：
- 附点 + 三连音：不稳定感
- 固定低音 ostinato：命运齿轮
- 切分：打破稳定

**命运动机**：
- 下行小二度（如 A→G#，贝多芬「命运动机」轮廓）
- 半音环绕（目标音上下各半音）

**曲式**（3 分钟 ≈ 90–110 小节 @ 100–120 BPM，4/4）：
- Intro 4–8 小节（低音 ostinato + 动机）
- A 主题 16 小节（可反复）
- B 发展 16 小节（情绪推进）
- C 桥段/高潮 8–16 小节
- A' 回归 8–16 小节
- Outro 4–8 小节（动机收束 / 皮卡第三度）

**吉他织体**（独奏曲，指弹为主）：
- 主旋律（lead，高音弦）
- 分解和弦伴奏（arpeggio，低音 + 中音弦）
- 融合：低音线 + 和声 + 旋律一体
