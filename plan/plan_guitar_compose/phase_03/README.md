# Phase 03 · 5 首打磨 + 录音 + 定稿交付（Week 04 · 11-16 → 11-20）

## 阶段目标

把 5 首从「能弹」提升到「能交付」：逐首打磨细节（力度 / 音色 / 段间过渡），确定专辑顺序与情绪曲线，完成录音/导出，交付 5 首原创吉他曲成品。

## 策略

- 先整体过一遍，列出每首的打磨点，再逐首精修（2 首/天），最后一天集中录音 + 导出。
- 录音用手机或声卡；至少一首可留 MuseScore 音频 demo 兜底。
- 5 首按「压抑 → 轮回 → 长夜 → 逆流 → 黎明」排序，形成完整情绪曲线。
