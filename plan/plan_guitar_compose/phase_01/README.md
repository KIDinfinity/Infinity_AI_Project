# Phase 01 · 创作方法论 + 第 1 首打样（Week 01 · 10-26 → 10-30）

## 阶段目标

建立可复用的「宿命感」创作语法（调式 / 和声 / 节奏 / 动机 / 曲式），并用它完整写出第 1 首《宿命之门》（约 3 分钟），跑通「动机 → 和声 → 段落 → 拼装 → 记谱 → 完整弹奏」全流程，为后 4 首立样板。

## 策略

- 第 1 天不急着写音符，先定 5 首的调式 / 和声 / 情绪，把「宿命感」翻译成可操作的音乐词汇。
- 后 4 天逐段完成《宿命之门》：动机 → A 段 → B/C 段 → 拼装 + 记谱 + 弹奏。
- 速度稳定在 100 BPM 上下；所有段落先慢速顺，再上目标速度。
