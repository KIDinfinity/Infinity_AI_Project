## 每日执行约定

- `PLAN.md`：当天计划（含今日知识点清单 + 30 分钟时间块 + 完成记录），计划生成后不随意改动。
- 当天未完成：次日不改 PLAN，只在当天 `PLAN.md` 的「完成记录」里写明顺延项，优先补完知识点而非跳过。
- 每周第 4 天固定为复习日（不学新内容），用于巩固本周 3 天知识点 + 易混淆点辨析。
