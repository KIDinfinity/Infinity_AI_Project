# Week 10 · 售卖物料准备

## 1. 本周核心目标

编写完整部署文档、录制演示视频与截图、制定授权价格体系，形成全套售卖物料。

## 2. 为什么这一周存在

用户购买前需要看得懂、信得过。物料决定产品能否被独立使用和信任。

## 3. 本周在整个半年路线中的位置

```
第 9 周产出：可商用产品
  ↓
本周：部署文档 + 演示视频/截图 + 价格体系
  ↓ 新产出
全套售卖物料
  ↓ 下一周输入
第 11 周用这些物料正式上架
```

## 4. 本周必须留下的资产

- 完整部署文档
- 演示视频 + 截图
- 授权价格体系

## 5. 本周验收标准（PASS/FAIL）

- [ ] 部署文档完整（一个陌生用户能照做部署成功）
- [ ] 演示视频/截图齐全
- [ ] 价格体系明确且已计入成本

## 6. 本周禁止事项

- 不夸大宣传，物料必须真实可复现
- 价格体系必须把支付/发卡手续费算进去

## 7. 如果只有 7 小时

必做：部署文档 + 价格体系。可删：视频精剪。

## 8. 完成本周后

下一周用物料上架并配置自助支付与自动交付。
