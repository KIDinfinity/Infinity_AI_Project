# Week 11 · 产品正式上架

## 1. 本周核心目标

把 DA-01 上架到产品平台/市场，配置官网自助支付与自动发货，云端正式部署上线，做到「公开可购买」。

## 2. 为什么这一周存在

这是从「有产品」到「能卖」的临界点，支付与自动发货是最关键的变现断点。

## 3. 本周在整个半年路线中的位置

```
第 10 周产出：售卖物料 + 价格体系
  ↓
本周：上架 + 自助支付 + 自动发货 + 云端部署
  ↓ 新产出
公开可购买的产品
  ↓ 下一周输入
第 12 周把 Agent 嵌入官网承接咨询
```

## 4. 本周必须留下的资产

- 已上架的产品页
- 自助支付 + 自动发货链路
- 云端正式部署

## 5. 本周验收标准（PASS/FAIL）

- [ ] 产品公开可购买
- [ ] 支付回调 + 自动发货链路可用（用测试订单验证）
- [ ] 云端正式部署上线

## 6. 本周禁止事项

- 不跳过支付回调/自动发货测试
- 不因「还没完美」拖延上架

## 7. 如果只有 7 小时

必做：上架 + 支付回调 + 自动发货。可删：云端部署优化。

## 8. 完成本周后

下一周把 Agent 嵌入官网，自动承接访客咨询。
