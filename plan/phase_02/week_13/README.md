# Week 13 · 被动引流搭建

## 1. 本周核心目标

AI 辅助写技术 SEO 文章、上线引流工具、完善官网收录（sitemap/提交），开启免费自然流量。

## 2. 为什么这一周存在

没有流量就没有咨询和订单。只靠被动流量，不主动营销，因此必须建 SEO 渠道。

## 3. 本周在整个半年路线中的位置

```
第 12 周产出：官网 + Agent
  ↓
本周：SEO 文章 + 引流工具 + 收录提交
  ↓ 新产出
免费自然流量入口
  ↓ 下一周输入
第 14 周监控访客咨询、跑首单
```

## 4. 本周必须留下的资产

- 技术 SEO 文章
- 引流工具/内容
- sitemap + 搜索引擎收录提交

## 5. 本周验收标准（PASS/FAIL）

- [ ] 有可检索的 SEO 内容
- [ ] 官网有 sitemap 且已提交收录
- [ ] 至少一条免费流量入口上线

## 6. 本周禁止事项

- 不做主动推广、不社群营销、不私聊拓客
- 不为 SEO 编造不实内容

## 7. 如果只有 7 小时

必做：sitemap + 收录提交 + 首批 SEO 文章。可删：引流工具。

## 8. 完成本周后

下一周监控访客与咨询，推动首单变现。
