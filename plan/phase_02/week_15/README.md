# Week 15 · AI 能力进阶调优

## 1. 本周核心目标

优化 RAG 召回与重排策略，修复问答幻觉，积累 badcase 调优笔记，显著提升 Agent 准确率。

## 2. 为什么这一周存在

第 14 周积累了真实问答数据，本周用它们系统调优，让 AI 从「能用」到「好用」。

## 3. 本周在整个半年路线中的位置

```
第 14 周产出：真实问答数据 + 首单
  ↓
本周：召回/重排调优 + 幻觉修复 + badcase 笔记
  ↓ 新产出
准确率提升的 Agent + 调优笔记
  ↓ 下一周输入
第 16 周基于调优后的产品做版本迭代
```

## 4. 本周必须留下的资产

- RAG 召回/重排策略优化记录
- 幻觉修复记录
- badcase 调优笔记

## 5. 本周验收标准（PASS/FAIL）

- [ ] 召回/重排至少一轮优化
- [ ] 已知幻觉案例被修复
- [ ] 调优前后有对比数据
- [ ] badcase 笔记沉淀

## 6. 本周禁止事项

- 不做没有基准的「感觉变好了」式调优
- 不为了准确率数字造假

## 7. 如果只有 7 小时

必做：召回优化 + 修主要幻觉。可删：重排、完整 badcase 笔记。

## 8. 完成本周后

下一周基于调优结果做产品版本迭代（轻量版等）。
