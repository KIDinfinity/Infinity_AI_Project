# Week 12 · Agent 官网落地

## 1. 本周核心目标

把 AI Agent 嵌入产品官网，调试线上问答效果，搭建工单归集，实现自动承接访客咨询。

## 2. 为什么这一周存在

用 Agent 承接 80% 被动咨询，减少人工沟通，是「睡后收入 + 低社交」的关键。

## 3. 本周在整个半年路线中的位置

```
第 11 周产出：已上架产品 + 官网
  ↓
本周：Agent 嵌入官网 + 线上问答调优 + 工单归集
  ↓ 新产出
官网智能问答机器人
  ↓ 下一周输入
第 13 周基于官网搭建被动引流
```

## 4. 本周必须留下的资产

- 官网嵌入的 Agent
- 线上问答效果调试记录
- 工单归集功能

## 5. 本周验收标准（PASS/FAIL）

- [ ] Agent 在官网可用
- [ ] 常见问题能被自动正确回答
- [ ] 无法回答的问题能归集到工单

## 6. 本周禁止事项

- 不让 Agent 答不了的问题凭空编造答案
- 不追求一次调到位，先跑通闭环

## 7. 如果只有 7 小时

必做：Agent 嵌入 + 常见问答可用。可删：工单归集细化。

## 8. 完成本周后

下一周用官网 + Agent 承接免费 SEO 被动流量。
