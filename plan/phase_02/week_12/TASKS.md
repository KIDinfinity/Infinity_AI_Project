# Week 12 · TASKS

## Task 1：Agent 嵌入官网

### 做什么
把第 7 周构建的 RAG/Agent 能力嵌入产品官网。

### 为什么做
让访客自助获得答案，减少人工咨询。

### 对 DA-01 的贡献
给 DA-01 增加自动客服能力，降低沟通成本。

### 前置依赖
第 11 周官网 + 第 7 周知识库/Agent。

### 具体执行步骤
1. 部署 Agent 前端组件。
2. 对接知识库检索链路。

### 验收标准
官网 Agent 可正常问答。

### 完成后的产出
官网智能问答机器人。

### 如果没有必要
若 DA-01 无需 AI 客服则跳过并记录。

## Task 2：线上问答调优

### 做什么
用真实访客问题调试线上问答效果，记录 badcase。

### 为什么做
线上问题比测试集更真实，需要持续校准。

### 对 DA-01 的贡献
提升 Agent 回答准确率。

### 前置依赖
Task 1。

### 具体执行步骤
收集真实问题 → 调优 → 更新知识库。

### 验收标准
常见问题能自动正确回答。

### 完成后的产出
调优记录。

### 如果没有必要
若无需 AI 则删除。

---

## Task 3：工单归集

### 做什么
对 Agent 无法回答的问题自动归集到工单。

### 为什么做
保证「答不了」的问题不丢失，仍可被动处理。

### 对 DA-01 的贡献
补足 Agent 的兜底，避免漏掉真实需求。

### 前置依赖
Task 1。

### 具体执行步骤
实现无法回答时的工单转接/记录。

### 验收标准
无法回答的问题能进入工单。

### 完成后的产出
工单归集功能。

### 如果没有必要
可降级为「记录到待办」的最简方案。
