# Phase 02 · 左手伴奏 + 双手合练（第 7–12 周 · Day29–Day56 · 11-26 → 01-04）

## 阶段目标

- 掌握左手伴奏的基本模式
- 逐页完成双手合奏
- **双手能慢速完整演奏「诀别书」全曲**

## 阶段策略

双手合练是最难的阶段。每段严格遵循「右手复习 → 左手单独 → 双手极慢合 → 逐步提速」的流程。
每天只合 2-4 小节，不贪多。每周 5 天（周一至周五），周末休息。
