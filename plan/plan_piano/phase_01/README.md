# Phase 01 · 基础入门 + 右手旋律（第 1–6 周 · Day01–Day30 · 10-19 → 11-27）

## 阶段目标

- 建立每日练琴习惯
- 掌握基本识谱能力（五线谱/简谱）
- 熟悉键盘布局与基本指法
- **右手能完整弹奏「诀别书」全曲旋律**

## 阶段策略

零基础起步，前两周重点放在「识谱 + 手指适应」上，不急于上曲子。
从 Week 02 开始逐步推进右手旋律，按谱子页码逐页攻克。
每周 5 天（周一至周五），周末休息。
