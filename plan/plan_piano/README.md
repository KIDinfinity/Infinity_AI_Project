# plan_piano — 「诀别书」电钢琴 3 个月学习计划

- **曲目**：诀别书（5页谱）
- **乐器**：电钢琴
- **起点水平**：零基础/入门
- **每日投入**：1 小时
- **总周期**：16 周（约 4 个月，每周 5 天，周一至周五）
- **起始日期**：2026-10-19（周一）
- **目标**：能完整、流畅地演奏「诀别书」

## 阶段总览

| Phase    | 周次       | 日期范围      | 主题                |
| -------- | ---------- | ------------- | ------------------- |
| Phase 01 | Week 01–06 | 10-19 → 11-27 | 基础入门 + 右手旋律 |
| Phase 02 | Week 07–12 | 11-30 → 01-08 | 左手伴奏 + 双手合练 |
| Phase 03 | Week 13–16 | 01-11 → 02-05 | 完整演奏 + 打磨成型 |

## 每日谱子

每个 `dayNN_*/sheet/` 下是该天要练的小节专属谱：

- `sheet.musicxml` — 用 MuseScore/Sibelius 打开看谱（左右手两个声部）
- `sheet.mid` — 可直接播放，用 DAW/播放器调速、分段听

全曲共 **106 个小节**（OMR 识别自 5 页谱），页边界：31 / 24 / 24 / 20 / 7。
