# Phase 03 · 完整演奏 + 打磨成型（第 13–16 周 · Day61–Day80 · 01-11 → 02-05）

## 阶段目标

- 从慢速过渡到原速
- 加入音乐表现力（强弱、情感、踏板）
- **有表现力地完整演奏 + 录制成品**

## 阶段策略

前两周专注提速和流畅度，后两周打磨细节和音乐性。
每周至少录音一次，客观评估并调整。每周 5 天（周一至周五），周末休息。
