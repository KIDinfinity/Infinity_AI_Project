# Day 28 外部资源清单

本文只记录当前部署尚未提供、需要准备的外部资源及其用途。拿齐资源后，可按同目录的 [SUMMARY.md](./SUMMARY.md) 执行部署和验收。

## 不需要另外申请

- **MinIO 凭据**：`.env.prod` 已包含本地生成的独立强凭据；部署时由 Compose 配置使用。若该文件曾分享给他人，应重新生成。
- **HTTPS 证书**：不需要手动购买或上传证书；今天用 Caddy `tls internal` 自动生成自签名证书即可（浏览器会提示警告，属预期）；后续换域名后 Caddy 会自动申请并续期 Let's Encrypt 受信证书。

## 准备完成检查

开始部署前确认：

1. 已拿到服务器公网 IP，云防火墙放行 22、80、443；服务器可通过 SSH 管理。
2. 已生成并配置部署 SSH 密钥，能以 `deploy` 用户登录。
3. `.env.prod` 中的 SiliconFlow Key、LLM Key、公网 IP（`WP_SITE_ADDRESS`）、`WP_TLS_DIRECTIVE=internal` 和 Basic Auth 用户/哈希均已填妥；没有 `<...>` 占位符。
4. Basic Auth 密码已更换为个人强密码，且 `.env.prod` 不提交到版本库。
5. （可选，后续再做）买域名、填 `ACME_EMAIL` 后按文中「域名」行说明切换，不影响今天的验收。
