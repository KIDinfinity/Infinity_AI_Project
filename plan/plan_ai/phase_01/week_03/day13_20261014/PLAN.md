权重（W1–8 阶段，合计 1.0）：

| 维度             | 代号 | 权重 | 1 分           | 5 分                    |
| ---------------- | ---- | ---- | -------------- | ----------------------- |
| 频率             | F    | 0.20 | 每月 ≤1 次     | 每天多次                |
| 单次耗时         | T    | 0.15 | < 5 分钟       | > 60 分钟               |
| AI 适配度        | AI   | 0.15 | 规则/计算类    | 非结构化文本理解/生成   |
| 数据可得且合规   | D    | 0.15 | 只能用公司机密 | 公开/自有/易脱敏        |
| 可评测性         | E    | 0.10 | 好坏说不清     | 有标准答案或可写 rubric |
| 求职相关度       | J    | 0.10 | JD 少见        | RAG/Agent 高频          |
| 商业化潜力       | B    | 0.05 | 只对自己有用   | 小团队普遍需要          |
| 实现成本（反向） | C    | 0.10 | 1–2 天         | > 3 周（计分用 6 − C）  |

$$Score = 0.20F + 0.15T + 0.15AI + 0.15D + 0.10E + 0.10J + 0.05B + 0.10(6 - C)$$

**算 Score 用脚本，不要手算**（避免算错后重做）：

```bash
uv run --with nothing python - <<'PY'
W = dict(F=.20, T=.15, AI=.15, D=.15, E=.10, J=.10, B=.05, C=.10)
rows = {
    "P-02": dict(F=5, T=3, AI=4, D=3, E=4, J=4, B=4, C=2),
    "P-07": dict(F=5, T=2, AI=4, D=4, E=4, J=5, B=3, C=3),
    "P-03": dict(F=4, T=3, AI=2, D=4, E=4, J=2, B=2, C=1),
}
for k, r in rows.items():
    s = sum(W[d] * (6 - r[d] if d == "C" else r[d]) for d in W)
    print(k, round(s, 2), "PASS" if (r["D"] >= 3 and r["E"] >= 3) else "BLOCKED")
PY
```
