## 5. 执行步骤

### 5.1 建追踪表（0–15 min）

```bash
mkdir -p ~/lab/projects/career/jds
cat > ~/lab/projects/career/applications.md << 'EOF'
# 投递追踪表

> 状态：已投递 / 初筛中 / 面试中 / Offer / 已拒 / 放弃
> 原则：不编造、不海投（本周 ≤ 5）、不主动私聊

| # | 公司 | 岗位 | 渠道 | 日期 | 简历版本 | JD匹配度 | 定制点 | 状态 | 反馈 |
|---|------|------|------|------|----------|----------|--------|------|------|
| 1 |      |      |      |      |          |          |        |      |      |
EOF
```

### 5.2 筛选岗位（15–35 min）

1. 打开 `career/jd-tracking.md`，筛选最近 4 周内收集的 JD
2. 排除：要求 8 年+ / 纯算法岗 / 不在目标城市 / 行业完全不匹配
3. 对剩余 8–10 个，用 AI 做匹配度打分：
   - 输入：JD 原文 + AI Full-Stack 简历
   - Prompt：「你是技术招聘方。给这份简历对这个 JD 的匹配度打分（1-5），列出匹配点、缺失关键词、建议定制方向。只基于简历中实际存在的内容判断。」
4. 选匹配度最高的 3–5 个

### 5.3 定制投递（35–70 min）

每个岗位做：

1. 根据 AI 建议调整简历：关键词替换（如 JD 写"向量数据库"→ 简历也用"向量数据库"而非"Vector DB"）、bullet 顺序（JD 强调的性能指标放前面）、项目侧重（如 JD 偏 Agent 则 P2 放第一个）
2. 导出定制版 PDF（文件名：`resume-ai-fullstack-{序号}.pdf`）
3. 在招聘平台正常投递
4. 记录到 `applications.md`
