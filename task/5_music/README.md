# 5_music — 诀别书风格原创曲生成流程

> 目标：生成一首「宿命感强、诀别书风格」的原创器乐，产出可试听、可演奏、可复现的谱子与音频。

## 一、风格锚点（先定死，再生成）

| 维度 | 取值 | 说明 |
|------|------|------|
| 调性 | D 小调 | 悲怆底色 |
| 速度 | ♩=60~72 | 慢板，留白感 |
| 拍号 | 4/4（可选 6/8 副歌流动段） | 主歌平稳 |
| 和声循环 | i–VI–III–VII（Dm–B♭–F–C） | 宿命循环，逃不掉的闭环 |
| 低音线 | 哀歌低音 D–C–B♭–A（下行四度链） | 无可挽回的下坠 |
| 动机 | 短主题反复 + 叹息音型（下行二度） | 反复=宿命，叹息=诀别 |
| 织体 | 左手分解和弦琶音 + 右手长线条旋律 | 诀别书典型钢琴织体 |
| 情绪曲线 | 平静 → 积累 → 爆发 → 破碎 → 消逝 | 高潮后不圆满，落回空寂 |

## 二、结构模板（约 2~3 分钟）

```
引子 Intro   (4 小节)  分解和弦动机，确立 Dm，低音点出 D
主题 A        (8~16)   主旋律第一次陈述，i–VI–III–VII
发展 B        (8~16)   旋律上移、加半音下行，张力积累
高潮 C        (8)      最高音区 + 最密集织体，爆发
再现 A'       (8)      主题回归但更破碎/更弱，宿命感
尾声 Coda     (4~8)    动机消逝，落回 Dm 长音，渐弱
```

## 三、生成流程（每步可独立重跑）

```text
① 写风格参数 spec.json   —— 调性/速度/拍号/和声循环/动机/结构
② 生成和声骨架           —— 按循环展开每小节的低音+和弦
③ 生成旋律               —— 动机 + 和弦音(经过/邻音) + 叹息音型
④ 生成伴奏织体           —— 左手分解和弦（根-三-五-八 摇摆型 / 八度低音）
⑤ 编排成整曲             —— 结构拼接 + 力度 + 渐强渐弱 + 渐慢
⑥ 导出 MusicXML + MIDI   —— music21 写出 .mxl / .mid
⑦ 渲染 PDF + MP3         —— mscore CLI 转谱 + 出音频成品
⑧ 试听 + 迭代            —— 宿命感不够 → 回 ① 调参重生成
```

## 四、产出物（每次生成一组）

```
task/5_music/
├── README.md            # 本流程
├── spec.json            # 风格参数（可编辑，重生成入口）
├── gen.py               # 生成脚本（music21）
├── out/
│   ├── song.musicxml    # 谱面（源）
│   ├── song.mid         # MIDI（试听/导入 DAW）
│   ├── song.pdf         # 演奏谱（2 页）
│   └── song.mp3         # 音频成品
```

## 五、工具链（复用现有）

- 生成：`music21`（`uv run --with music21 python gen.py`）
- 渲染：`mscore` CLI（tools/music/score 同款）

## 六、验收标准

- [x] `out/song.mid` 可播放，结构完整（引子→A→B→C→A'→尾声）
- [x] `out/song.pdf` 可渲染成谱（2 页）
- [x] 和声确为 i–VI–III–VII + 哀歌低音（写入 gen.py，可机器验证）
- [x] 叹息动机贯穿全曲（A→G / F→E / A5→G5→F5 反复，宿命反复）
- [x] `out/song.mp3` 已出音频成品（约 3:25）
- [x] 改 `spec.json` / gen.py 参数可复现新版本（可复现）

## 七、重新生成

```bash
uv run --with music21 python gen.py                 # 生成 musicxml + midi
mscore -o out/song.pdf out/song.musicxml            # 渲染演奏谱
mscore -o out/song.mp3 out/song.musicxml            # 渲染音频成品
```
